Simple static portfolio

Files:
- index.html — main page
- styles.css — styles
- script.js — small JS for nav and form

Open locally:
- Double-click index.html to open in your browser, or
- Serve with Python (recommended):
  cd port
  python3 -m http.server 8000
  Open http://localhost:8000

This is a minimal starter — edit the HTML to add your name, projects, and links.
