===============================================================================
ARCHITECTURAL CHANGES:
===============================================================================

Problem:
--------
Synchronous tool functions (manage_file) trying to call async functions
(broadcast_log, broadcast_file_change) using asyncio.create_task() in
a context with no running event loop.

Solution:
---------
Queue-based notification system:

1. Sync Context (tool execution):
   - Call notify_file_change() [synchronous]
   - Appends to file_change_queue
   - Returns immediately

2. Async Context (server processing):
   - Call process_file_change_queue() [async]
   - Processes queued notifications
   - Broadcasts via WebSocket

Flow:
-----
manage_file [sync]
  → notify_file_change [sync]
    → queue.append()
      [Later in async context...]
      → process_file_change_queue [async]
        → broadcast_file_change [async]
          → WebSocket send
